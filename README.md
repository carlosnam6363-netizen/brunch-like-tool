# Brunch Like Tool (브런치 연재글 자동 좋아요 도구)

브런치스토리(Brunch Story) 플랫폼에서 사용자가 지정한 요일에 올라온 연재 글들을 **최신순**으로 정렬하여 **1분 간격**으로 순차적으로 '좋아요(라이킷)'를 눌러주는 자동화 애플리케이션입니다.

> **기본 목표 대상 URL**:  
> `https://brunch.co.kr/serial/list#tue#PUBLISH_TIME` (화요일 연재 최신순)

---

## 🌟 주요 기능

1. **요일 및 정렬 필터링**:
   - 요일: 월(mon), **화(tue - 기본값)**, 수(wed), 목(thu), 금(fri), 토(sat), 일(sun), 완결작(com)
   - 정렬: **최신순(PUBLISH_TIME - 기본값)**, 인기순(POPULARITY)
2. **정확한 1분 간격 좋아요**:
   - 계정 제재 및 어뷰징 방지를 위해 글 하나당 **1분(60초, 사용자 변경 가능)** 간격을 두고 순차 실행합니다.
   - 실시간 남은 초 카운트다운 타이머가 표시됩니다.
3. **중복 좋아요 방지 (스마트 스킵)**:
   - 이미 내가 좋아요를 누른 글은 자동으로 감지하여 건너뛰므로 좋아요가 취소되는 불상사가 없습니다.
4. **1회 카카오 로그인 영구 보존**:
   - `brunch_profile/` 세션 디렉토리에 브라우저 쿠키와 계정 정보가 안전하게 유지되므로, **최초 1회만 카카오 로그인**을 해두면 이후에는 별도 로그인 없이 자동으로 실행됩니다.
5. **다양한 인터페이스 지원**:
   - **데스크톱 GUI (`gui.py` / `run_gui.bat`)**: 원클릭 실행 가능한 직관적인 윈도우 창 인터페이스
   - **웹 대시보드 (`app.py` / `run_web.bat`)**: Streamlit 기반의 깔끔한 웹 대시보드
   - **CLI 명령줄 도구 (`cli.py`)**: 스케줄러나 배치 작업용

## 📁 프로젝트 구조

```
brunch-like-tool/
├── brunch_api.py      # 브런치 공식 API 연동 모듈 (요일/정렬별 글 목록 및 메타데이터 수집)

├── run_gui.bat        # 윈도우 원클릭 GUI 실행기
├── run_web.bat        # 윈도우 원클릭 Web 실행기
```

## 🚀 사용 방법

### 1. 프로그램 실행 (택 1)

#### 방법 A: 데스크톱 GUI 실행 (가장 추천)
- `run_gui.bat` 파일을 더블클릭하거나 터미널에서 다음 명령어를 실행합니다:
  ```bash
  python gui.py
  ```

#### 방법 B: 웹 대시보드 실행
- `run_web.bat` 파일을 더블클릭하거나 터미널에서 다음 명령어를 실행합니다:
  ```bash
  streamlit run app.py
  ```

#### 방법 C: CLI 실행 (터미널)
- 화요일(tue) 최신순(PUBLISH_TIME) 60초 간격 기본 실행:
  ```bash
  python cli.py --day tue --order PUBLISH_TIME --interval 60
  ```

---

### 2. 사용 단계 안내

1. **[1. 카카오 로그인 브라우저 열기] 버튼 클릭**:
   - 브라우저 창이 열리면 브런치 사이트에서 **카카오 계정으로 로그인**을 완료합니다.
   - 로그인 완료 후 브라우저 창을 닫아도 세션이 영구적으로 보존됩니다.
2. **[2. 연재 글 목록 불러오기] 버튼 클릭**:
   - 설정한 요일(기본: 화요일)과 정렬 기준(기본: 최신순)에 해당하는 브런치 연재 글 전체를 즉시 조회하여 목록에 나열합니다.
3. **[3. 자동 좋아요 시작] 버튼 클릭**:
   - 목록의 첫 번째 글부터 1분 간격으로 접속하여 좋아요를 클릭합니다.
   - 작업 중 언제든 **[일시정지]** 또는 **[중단]**이 가능합니다.

## ⚙️ 옵션 상세 설명

| 항목 | 기본값 | 설명 |
|---|---|---|
| **요일** | 화요일 (`tue`) | `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`, `com` |
| **정렬** | 최신순 (`PUBLISH_TIME`) | `PUBLISH_TIME`(최신순), `POPULARITY`(인기순) |
| **간격** | 60초 (1분) | 연속 호출 방지를 위한 지연 대기 시간 (초) |
| **브라우저** | Chrome | `chrome` 또는 `edge` 중 선택 가능 |

## 🔒 보안 및 개인정보

- 사용자의 카카오 아이디/비밀번호는 코드에 직접 저장되지 않으며, 사용자의 로컬 브라우저 프로필(`brunch_profile/`)에만 안전하게 보관됩니다.
- 본 도구는 공식 API 목록 조회와 실제 브라우저 기반 상호작용을 결합하여 사이트 정책을 준수하는 방식으로 작동합니다.
