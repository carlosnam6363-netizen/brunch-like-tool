💖 브런치 연재글 자동 좋아요

언제 어디서든 스마트폰과 웹 브라우저로 실행하는 올인원 웹 포털

🚀 웹에서 바로 실행하기

설치 없이 스마트폰, 태블릿, 다른 PC의 브라우저에서 버튼 하나로 웹 대시보드를 열어 자동 좋아요를 실행합니다.

☁️ Streamlit Cloud로 1초 웹 배포 (24시간 상시 가동) ⚡ GitHub Actions에서 즉시 실행 (클라우드 러너) 🌐 현재 가동 중인 원격 웹 대시보드 바로가기

🍪 1초 브런치 쿠키 복사 도구

브런치(brunch.co.kr)에 로그인한 후, 아래 북마크릿 코드를 브라우저 주소창 또는 콘솔에 붙여넣으면 인증 쿠키가 즉시 클립보드에 복사됩니다:

javascript:(function(){navigator.clipboard.writeText(document.cookie);alert('✅ 브런치 쿠키가 클립보드에 복사되었습니다!');})();

✨ 핵심 기능 안내

  • 🎲 1초 ~ 30초 무작위 랜덤 간격: 일정한 주기가 아닌 무작위 시간 간격으로 지연 대기하여 어뷰징 감지를 완벽하게 방지합니다.
  • 💖 우측 상단 GNB 하트 정밀 타겟팅: 글 접속 시 화면 최상단 우측에 위치한 하트 아이콘(라이킷)을 정밀 감지하여 클릭합니다.
  • ⚡ 이미 누른 글 자동 스킵: 이미 좋아요를 누른 글은 불필요한 요청 없이 0.01초 내에 감지하여 안전하게 건너뜁니다.
  • 📅 특정 요일 최신순 전체 순회: 화요일(tue)을 비롯하여 월~일/완결작 글을 최신순(PUBLISH_TIME)으로 전체 자동 처리합니다.
