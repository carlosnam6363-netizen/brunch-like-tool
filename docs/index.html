💻 [방법 2] 내 PC에서 더블클릭 1초 실행

웹 호스팅이나 클라우드 설정 없이, 내 컴퓨터 폴더에서 파일 하나만 더블클릭하면 즉시 실행됩니다:

🪟 윈도우 창 프로그램 실행: run_gui.bat 더블클릭 ➡️ 창이 뜨고 버튼 클릭으로 실행
🌐 로컬 웹 대시보드 실행: run_web.bat 더블클릭 ➡️ 브라우저에서 직관적 3단계 실행

📱 [방법 3] 스마트폰으로 접속하고 싶을 때

내 PC에서 run_remote_web.bat을 더블클릭하면 검은 창에 스마트폰 접속용 보안 주소(HTTPS)가 즉시 발급됩니다.

아이폰, 갤럭시 모바일 브라우저로 접속하여 버튼 터치로 좋아요를 누를 수 있습니다 (GitHub Actions / Streamlit Cloud 불필요).

✨ 핵심 자동화 기능

  • 🎲 1초 ~ 30초 무작위 랜덤 간격: 고정 시간이 아닌 무작위 시간 지연 대기로 어뷰징 차단을 완벽 방지합니다.
  • 💖 우측 상단 GNB 하트 정밀 타겟팅: 글 접속 시 화면 상단 우측의 하트 아이콘(라이킷)을 찾아 안전하게 클릭합니다.
  • ⚡ 이미 누른 글 지연 없이 즉시 스킵: 이전에 좋아요를 눌렀던 글은 별도 대기 시간 없이 다음 글로 즉시 넘어갑니다.
